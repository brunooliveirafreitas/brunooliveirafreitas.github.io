O que verificar antes da instalação?

Espessura da porta de vidro de 2,5 a 7 cm. A FD 1000 D é aplicável dentro dessa faixa — medir com régua antes ajuda a confirmar.
Acesso às pilhas. O modelo usa 4 pilhas AA. Verifique se há espaço suficiente no compartimento.
Vidro temperado. A FD 1000 D é indicada para portas de vidro temperado. Vidro comum não é compatível.
Altura de instalação confortável. Definimos junto com você a altura ideal do teclado, geralmente na altura do maçaneto original.
Wi-Fi ou hub. O app funciona via Bluetooth. Para controle remoto, é necessário um hub Intelbras.
